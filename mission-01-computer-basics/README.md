### IPOS trace: typing and saving a document
| Stage | What happens in my example? | Hardware/component |
|---|---|---|
| Input | I type in the editor and press Save. | Keyboard and pointer device |
| Processing | The application turns keystrokes into document changes and prepares the file data. | CPU and RAM |
| Output | The saved status and document are displayed on screen. | Screen and editor interface |
| Storage | The document is written to permanent storage. | SSD and, if used, cloud storage |

The activity moves from keyboard input through CPU and memory processing, to visible feedback and finally to a storage location.
